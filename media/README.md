# media/

Reference imagery, demo videos, prototype photos, anything visual that isn't a final deliverable (those go in `deliverables/`).

## Suggested layout

```
references/        # Swiss Museum DJ table, Gramazio Kohler, Fologram, EPFL SXL ...
prototypes/        # photos/videos of our work-in-progress
inspiration/       # mood images, sketches
```

## Conventions

- Keep individual files under ~20 MB if possible. Anything heavier → cloud storage, link from here.
- Source attribution: if a reference image isn't ours, drop a `.txt` next to it with the source URL.
- For videos, prefer `.mp4` (H.264) — plays everywhere.
