01 — The Building Block

The Artificial Neuron

Every neural network — from image classifiers to Claude — is built from the same primitive unit: the artificial neuron. It takes several numbers as inputs, multiplies each by a learned weight, sums them with a bias, then squashes the result through an activation function to decide how strongly to fire.

output = σ( w₁·x₁ + w₂·x₂ + w₃·x₃ + b )

The weights and bias are what the network learns during training. Billions of tiny adjustments over trillions of examples add up to intelligence. Drag the sliders to see the neuron respond in real time.

02 — Going Deep

Deep Neural Networks

Stack neurons into layers, connect the layers, and you get a deep neural network. Data flows forward: each layer transforms the representation, extracting increasingly abstract features. Early layers detect edges. Later layers detect concepts.

"Deep" just means many layers of transformations stacked in sequence. GPT-3 applies a learned transformation 96 times before producing any output. Claude applies it even more — across dozens of attention heads per layer.

03 — Seeing Patterns

Convolutional Neural Networks

CNNs learn to see by sliding a small filter (a grid of learned weights) across an image, computing a dot product at each position. The filter learns to activate on specific patterns — an edge, a corner, a texture. Stack hundreds of these filters and the network builds a rich description of what it sees.

Claude doesn't use CNNs — but the ideas of local pattern detection and hierarchical feature extraction are foundational to all deep learning. The filter below is a Sobel edge detector.

04 — The Revolution

Attention & Transformers

In 2017, a paper called "Attention is All You Need" changed everything. Instead of reading left-to-right, the Transformer lets every word attend to every other word simultaneously — weighting how relevant each one is to the current word's meaning.

When Claude reads "The bank by the river eroded", it uses attention to link "bank" to "river" (geography, not finance) and "eroded" to "bank" (what wore away). Claude does this across billions of parameters, dozens of attention heads, for every single token.

05 — The Numbers

Parameters: The Scale of Claude

A parameter is a single learnable number — one synaptic weight in the network. Modern LLMs have hundreds of billions. Each is nudged, over trillions of training examples, until the network can predict what text comes next in any context.

Anthropic has not disclosed Claude's exact parameter count. Independent estimates place it between 500 billion and over 1 trillion — comparable to GPT-4. What is known: it was trained on hundreds of billions of tokens of text and refined with RLHF.
Parameter scale comparison

For context: the human brain has ~86 billion neurons and an estimated 100 trillion synaptic connections. A large LLM sits between those in raw count — but biological synapses are analog, dynamic, and run on 20 watts. Claude runs on megawatts of data-center power.

06 — How It Learned

Training: Making a Mind

The model starts with random weights — pure noise. It reads a sentence, predicts the next word, checks if it was right, then adjusts every parameter slightly via gradient descent. Repeat ~10²² times. The weights that survive are the ones that captured the patterns of human language and reasoning.

01
Pre-training
Predict the next token. Billions of documents. Learns grammar, facts, logic, and world knowledge.
02
Supervised Fine-tuning
Human-written example conversations teach the model how a helpful assistant should respond.
03
RLHF
Human raters score response pairs. The model learns to prefer answers that are helpful, harmless, and honest.
The result is a model with no memory between conversations, no live internet access by default, and no "understanding" in the human sense — but extraordinary pattern-matching across a vast compressed representation of human knowledge. That is Claude.
